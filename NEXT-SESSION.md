## Validation checklist

1. Exercise Tree, Ouroboros, Mandala, and Within views; confirm transitions are
   legible and that the same population feels coherent across aspects.
2. Test pause, pulse, force application, and reset, then sweep awakening,
   choice, resistance, cycle speed, and population controls.
3. Move the logical population to one million and watch frame rate, input
   responsiveness, memory use, and the browser console for WebGL errors.
4. Repeat a compact pass on a phone-sized viewport or physical mobile browser.
5. Capture one screenshot or short recording for each aspect once the visual
   hierarchy is accepted.

## Decisions after review

- Choose the next simulation improvement from the existing design direction;

- Decide explicitly whether the project should receive an open-source license.
