# Soul Tree

A real-time creative simulation of individual souls moving through lives,
reincarnating through a shared root, making choices, and gradually recognizing
the unified body formed by their journeys.

This is speculative art, not a religious, scientific, or metaphysical claim.

## Run

```bash
npm install
npm run dev
```

The development server prints local and LAN URLs. Build the static application
with:

```bash
npm run build
```

## What is actually simulated

- Every rendered point has a stable lineage, awakening threshold, life rate,
  and inherited path.
- During each incarnation it can retain that inherited branch or choose a new
  branch according to the Choice force.
- The embodied part of the cycle rises from root to crown. The short hidden
  portion travels around the exterior from death back to birth.
- Recognition is individual but spreads as a field. Awakened souls retain their
  distinct motion while bending toward a shared destination.
- Resistance deforms and delays unawakened souls at the upper threshold.
- Collective coherence eventually weakens that boundary. Resistance therefore
  shapes the emergence rather than merely serving as an enemy.

The population control represents up to one million souls. For GPU stability,
the browser renders at most 180,000 points on desktop and 90,000 on small
screens; above that, each point represents a small aggregate with identical
statistical behavior.

## Four aspects

All views observe the same structure:

- **Tree:** time appears as ascent, choice as branching.
- **Ouroboros:** the exterior reincarnation current closes death back into birth.
- **Mandala:** twelve lineages and their choices become a rotating petal field.
- **Within:** scale and objecthood fall away; the viewer occupies the current.
